# Dayflow CN 中文版安装说明

## 📦 应用信息
- **应用名称**: Dayflow CN
- **版本**: v1.1.21-cn
- **Bundle ID**: teleportlabs.com.Dayflow.cn

## 🚀 安装方法

### 方法1：直接拖拽安装（推荐）
1. 解压 `Dayflow_CN_v1.1.21.zip` 文件
2. 将 `Dayflow CN.app` 拖拽到 `应用程序` 文件夹
3. 首次运行时，系统会提示权限请求

### 方法2：命令行安装
```bash
# 解压文件
unzip Dayflow_CN_v1.1.21.zip

# 复制到应用程序文件夹
cp -R "Dayflow CN.app" /Applications/
```

## 🔐 权限设置

首次运行需要授予以下权限：

1. **屏幕录制权限**：
   - 打开 `系统设置` → `隐私与安全` → `屏幕录制`
   - 找到 `Dayflow CN` 并启用

2. **系统音频录制权限**（可选）：
   - 打开 `系统设置` → `隐私与安全` → `麦克风`
   - 找到 `Dayflow CN` 并启用

## 💡 重要说明

### ✨ 这个版本的特点
- **完整中文AI支持**：所有AI生成的内容都是中文
- **数据独立**：与正式版完全隔离，不会影响现有数据
- **中文界面**：应用显示为"Dayflow CN"

### 🎯 AI功能配置
这个版本已经内置了中文提示词，支持以下AI服务：
- **Gemini**：需要配置API密钥
- **本地模型**：支持Ollama或LM Studio

### 📊 数据存储
- 数据存储位置：`~/Library/Application Support/Dayflow CN/`
- 与正式版完全独立，互不影响

## ❓ 常见问题

**Q: 无法启动应用？**
A: 检查系统设置中的屏幕录制权限是否已授予Dayflow CN

**Q: AI生成内容不是中文？**
A: 这个版本已经修复了该问题，所有AI提示词都是中文的

**Q: 和正式版有冲突吗？**
A: 完全没有冲突，两个版本可以同时运行，数据完全独立
